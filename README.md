# A Golden Birthday Night — Như

Concept: sang trọng + tối giản + 3D hiện đại, đen và vàng champagne.

Cách chạy:
1. Giải nén file ZIP.
2. Mở `a-golden-birthday-night/index.html`.
3. Dùng Chrome, Safari, Edge hoặc Firefox bản mới.

Không cần Node.js, npm hay internet.

Các cảnh:
1. Không gian tối + ánh sáng champagne
2. Happy Birthday Như
3. Hộp quà + lời chúc dễ thương
4. Bánh sinh nhật + thổi nến
5. Ngôi sao ghép thành chữ NHƯ
6. Ending + From Tuấn Kiệt + pháo hoa

Nhạc piano nhẹ được tạo bằng Web Audio sau lần tương tác đầu tiên.
